# FocusTV Website Rebuild

## Decision Log

This file records decisions that future developers or AI assistants may otherwise question.

Do not delete old decisions. If a decision changes, add a new entry that supersedes it.

---

## DEC-001 - Rebuild Instead of WordPress Redesign

**Status:** Accepted

**Decision:**  
Build a completely new code-based website rather than redesigning the existing WordPress frontend.

**Reason:**  
The new project requires better performance, cleaner code, stronger creative control, and a significantly more premium experience.

**Impact:**  
The old website is only a possible content/URL reference. Its frontend architecture is not reused.

---

## DEC-002 - Next.js as Primary Framework

**Status:** Accepted

**Decision:**  
Use Next.js App Router with TypeScript.

**Reason:**  
The project owner already understands basic React, Next.js is widely supported by AI coding tools, it provides a strong path for SEO and future functionality, and it keeps the project inside the broader React ecosystem.

**Impact:**  
The codebase should remain simple and avoid turning a mostly static website into a complex application.

---

## DEC-003 - No CMS

**Status:** Accepted

**Decision:**  
Do not add a CMS for v1.

**Reason:**  
The client will not manage content directly. The project owner/developer will handle future updates.

**Impact:**  
Content should be stored in maintainable source files or structured local data.

---

## DEC-004 - No Database Initially

**Status:** Accepted

**Decision:**  
No database for initial release.

**Reason:**  
Current requirements do not need persistent application data.

**Impact:**  
Contact and meeting functionality should remain lightweight.

---

## DEC-005 - CSS Modules Instead of Tailwind

**Status:** Accepted

**Decision:**  
Use CSS Modules + CSS Custom Properties.

**Reason:**  
The project must be readable for a basic/intermediate frontend developer and should avoid large utility-class strings generated by AI.

**Impact:**  
Create and maintain a clear token system.

---

## DEC-006 - Dual Theme

**Status:** Accepted

**Decision:**  
Default light theme with optional dark cinematic theme.

**Reason:**  
Client approved both themes.

**Impact:**  
Every reusable visual component should support both themes.

---

## DEC-007 - Brand Gold

**Status:** Accepted

**Decision:**  
Use `#BF8B25` as the core FocusTV brand accent.

**Impact:**  
Gold should be controlled, not used as a dominant background everywhere.

## DEC-008 - Premium Motion Stack

**Status:** Accepted

**Decision:**  
Use Lenis + GSAP/ScrollTrigger.

**Reason:**  
The desired experience includes smooth scrolling and high-quality reveal motion inspired by premium automotive/creative websites.

**Impact:**  
Animation must remain performance-conscious and accessible.

## DEC-009 - Custom Cursor

**Status:** Accepted

Use a custom cursor on supported desktop pointer devices.

No custom cursor on touch devices. It must not reduce usability.

**Status:** Accepted

**Decision:**

## DEC-020 - Sprint 1 Visual System & Shell Decisions

**Status:** Accepted

**Decision:**

1. **Typography Pairing:** Primary modern sans-serif `Manrope` combined with secondary editorial serif `Cormorant Garamond` (used for high-impact statements).
2. **Zero-Flash Theme Persistence:** Inline initialization script in `<head>` sets `data-theme` attribute before hydration, synchronized with `localStorage` and `ThemeProvider` state.
3. **Desktop Fine-Pointer Cursor:** `CustomCursor` is enabled exclusively on `(pointer: fine)` devices without `prefers-reduced-motion`.
4. **Smooth Scroll Isolation:** Single `Lenis` instance configured via `SmoothScrollProvider`, with instant fallback under `prefers-reduced-motion`.
5. **Temporary Brand Mark:** Use clean text mark `FOCUSTV` until official visual assets are provided.
